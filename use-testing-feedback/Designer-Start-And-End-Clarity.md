## Designer Start and End Clarity

 - Users want a way to easily understand what is the 'start' versus the 'end' of a workflow in the UX.
 - It is not clear to users how to identify the start and end of a workflow, especially when there are multiple modules and connections.
 - We should have a way to color or otherwise delineate the start and end of a given workflow in the designer.
   - Ideally, the UI when validating the workflow should show a clear indication of what is the start and end of the workflow.
     - or if not clear provide something that provides a different indication to show where confusion is (e.x. multiple possible start or end points)
 - A way to explicitly set the expected start/end via right click on a module and selecting "Set as Start" or "Set as End" would be helpful as well
   - We should still try to allow for 'happy path' on simple flows where we autodetect like today.
